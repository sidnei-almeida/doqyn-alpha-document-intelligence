================================================================================

BUG-001 (crítico): race condition no UploadQueueProvider.
O useEffect dependia de `items` e usava cleanup `cancelled=true`, cancelando
analyzePdf assim que o status mudava para `analyzing`.

a promise in-flight por mudança de estado React. Timeout de 180s para analyzing.

BUG-002: extraction:null causava 400 INVALID_PAYLOAD no confirm.
Solução: normalizeAnalyzePayloadForConfirm no frontend antes do POST.

3. RACE CONDITION — COMO FOI CORRIGIDO
================================================================================

Antes:
  useEffect([items]) → dispatch analyzing → items muda → cleanup cancelled →
  analyzePdf resolve ignorado → item preso em analyzing.

Depois:
  - processingItemIdRef marca item em análise (não usa cancelled flag)
  - pumpQueue só inicia se não há processingItemIdRef, hasActiveItem, countdown
  - tryPumpQueue via queueMicrotask após conclusão/erro/review
  - analyzeTimeoutRef: 180s → error "A análise demorou mais que o esperado"
  - removeItem limpa processingItemIdRef se item removido durante análise

================================================================================

Arquivo: normalizeConfirmPayload.ts
