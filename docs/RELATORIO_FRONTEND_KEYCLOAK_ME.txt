================================================================================

  src/auth/AuthProvider.tsx → loadKeycloakSession()

    2. registerAuthTokenGetter(token)
    3. getCurrentSession()

  src/features/auth/authApi.ts → meRequest()
  GET /api/auth/me (reexport) — parseia legacyUser ou mapMeSessionToAuthUser


================================================================================
3. COMO O CONTEXTO É MONTADO
================================================================================

Após resposta de /api/me:

  mapMeSessionToAuthUser(session) → AuthUser
    - companyId  ← tenant.tenantId
    - companyName ← tenant.displayName
    - roles      ← membership.tenantRoles
    - groups     ← membership.accessGroupIds

AuthContext expõe:
  user, tenant, membership, token, roles, accessGroupIds,
  accessGate, isAuthenticated, hasRole, hasAnyRole, logout, ...

Regras:
  - roles preferencialmente de membership.tenantRoles
  - tenantId oficial de tenant.tenantId (não hardcoded)
  - isAuthenticated = user presente E accessGate === null
