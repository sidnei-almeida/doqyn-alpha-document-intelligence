================================================================================
1. CAUSA RAIZ
================================================================================

Mismatch entre slug e categoryId real na query ?space=.

O parâmetro ?space= na URL era repassado literalmente para listDocuments como
categoryId, mas o Mongo armazena classId canônico (ex.: cat_juridico).

Evidência Mongo (documents_company_dev, tenant company_dev):
- Documento: doc_98b4957e-e272-4102-9010-851ec1018955
- currentFileName: juridico_ACORDO_DE_CONFIDENCIALIDADE_...pdf
- classId: cat_juridico
- className: Jurídico
- status: active
- processingStatus: processed

Consultas simuladas:
- classId = cat_juridico  → 2 documentos
- classId = juridico (slug) → 0 documentos

A URL /biblioteca?space=juridico (slug) era válida semanticamente mas a API
filtrava pelo valor errado. O documento continuava visível em Recentes/raiz
(listagem sem categoryId), mas sumia ao abrir a pasta.

Fatores agravantes corrigidos:
- keepPreviousData reutilizava lista da raiz ao trocar de pasta (cache visual)
- Abrir pasta não limpava filtros (q/status) herdados de outra view
- Filtro "Processado" não incluía processingStatus processed_with_review
- canUserListDocument exigia canPreview (corrigido para view OU download)

4. TIPO DE BUG
================================================================================

Principal: categoryId / slug (filtro)
Secundários: cache React Query (keepPreviousData), filtros herdados na URL,
mapeamento do filtro Processado, listagem atrelada a canPreview.

Renderização/thumbnail NÃO era a causa — cards já tinham fallback de ícone.

5. CORREÇÕES APLICADAS
================================================================================

Novo utilitário resolveLibraryCategoryId / findLibraryCategory:
- Resolve id, slug ou nome → categoryId canônico

buildLibraryDocumentFilters:
- Usa categorias do tenant para resolver ?space=
- scope=all + busca remove categoryId (busca em toda biblioteca)
- libraryListScopeKey para chave de escopo de listagem

useLibraryView:
- Carrega categorias; normaliza URL slug → id canônico
- Passa categorias ao builder de filtros

LibraryPage:
- activeSpace via findLibraryCategory
- openSpace limpa q/status/type/period/owner/scope ao entrar na pasta

WorkspaceLayout:
- Drag-and-drop resolve slug para categoryId

useDocuments:
- Removido keepPreviousData
- queryKey inclui listScopeKey (não reutiliza cache raiz ↔ pasta)

documentService (mínimo):
- processingStatus=processed inclui processed_with_review

documentAccess:
- canUserListDocument permite listar com view OU download (não só preview)
