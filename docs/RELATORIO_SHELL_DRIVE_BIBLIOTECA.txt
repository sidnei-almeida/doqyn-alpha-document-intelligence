RELATÓRIO — Refinamento visual shell Drive-inspired (DOQYN Alpha)
================================================================
Data: 2026-07-07

OBJETIVO
--------
Aproximar a composição espacial do workspace DOQYN da sensação do Google Drive
(shell arredondado, canvas inset, menos divisórias, tipografia limpa), sem copiar
branding Google e sem alterar backend, APIs, upload/analyze/confirm ou auth.

1. APP SHELL / CONTAINER PRINCIPAL
----------------------------------
Estrutura em camadas:

  app-chrome (fundo externo, padding inset)
    └── app-shell (superfície arredondada, sombra sutil)
          ├── Sidebar (integrada, sem border-r)
          └── workspace-frame
                ├── WorkspaceTopBar (sem border-b)
                └── workspace-canvas
                      └── workspace-canvas-inner (canvas arredondado, scroll)

Arquivos:
- src/app/layout/WorkspaceLayout.tsx — refatorado
- src/styles/globals.css — classes .app-chrome, .app-shell, .workspace-canvas,
  .workspace-canvas-inner
- src/styles/tokens.css — tokens de superfície e raio
- tailwind.config.js — cores chrome/shell/canvas, radius shell/workspace

Tokens novos/ajustados:
- --bg-chrome, --bg-shell, --bg-canvas
- --radius-shell: 20px, --radius-workspace: 16px
- --shell-inset: 10px
- --shadow-shell (dark e light)

2. DIVISÓRIAS REMOVIDAS / SUAVIZADAS
------------------------------------
- Sidebar: removido border-r; separador Admin usa h-px com opacidade (não border-t)
- Topbar: removido border-b
- Busca global: removida borda do atalho ⌘K; fundo mais suave (surface)
- ExplorerFolderFiles: thead sem sticky/blur pesado; cabeçalhos discretos
- ExplorerFolderCard: removido hover com borda; só hover de fundo
- explorer-icon-btn: hover com overlay-hover (mais leve que bg-surface-2)

3. TIPOGRAFIA
-------------
Fonte escolhida: Inter Variable (@fontsource-variable/inter)
- Substituída Geist Sans como fonte principal do app
- Geist Mono mantida apenas para monospace
- tokens.css: --font-family-sans e --font-family-logo atualizados
- tailwind.config.js: fontFamily.sans → Inter Variable

4. ÍCONES
---------
Biblioteca mantida: lucide-react (já no projeto)
- Stroke 1.5 via LUCIDE_STROKE
- Ícones de arquivo/pasta sem caixa bg-doqyn-card no explorer
- Tamanho 20px (h-5 w-5) em listas compactas

5. PASTAS (RAIZ DA BIBLIOTECA)
------------------------------
ExplorerFolderCard:
- Tile horizontal drive-folder-tile, min-h 44px
- Ícone Folder à esquerda, metadado discreto (contagem)
- Menu/info no hover à direita
- Sem borda no hover — apenas bg-doqyn-surface-hover

6. LISTAS / RECENTES / PASTA INTERNA
------------------------------------

- ExplorerFolderFiles: cabeçalho leve, sem backdrop administrativo
