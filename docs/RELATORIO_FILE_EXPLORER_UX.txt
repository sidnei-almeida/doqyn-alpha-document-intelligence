1. DIAGNÓSTICO DA UX ANTERIOR
--------------------------------------------------------------------------------
A tela /biblioteca estava organizada como um dashboard administrativo:
- Cards de pastas no topo com comportamento de seleção (radio/checkbox).
- Tabela de arquivos sempre visível abaixo, filtrada pela pasta selecionada.
- Clicar em uma pasta não "abria" a pasta — apenas filtrava a tabela.
- O usuário não sentia navegação em um gerenciador de arquivos.
- Pastas e arquivos competiam pelo mesmo espaço visual sem hierarquia clara.

2. NOVA EXPERIÊNCIA FILE EXPLORER
--------------------------------------------------------------------------------
Raiz (/biblioteca):
- Breadcrumb: Biblioteca
- Título: Biblioteca
- Grid protagonista de pastas inteligentes (categorias de governança).
- Cada pasta mostra ícone, nome, contagem, descrição (se houver), governança e menu.
- Clique ou duplo clique abre a pasta.
- Seção opcional "Sem categoria" para documentos sem classId.
- Sem tabela administrativa gigante na raiz (toolbar de arquivos oculta).

Dentro da pasta (/biblioteca?space={categoryId}):
- Breadcrumb: Biblioteca / {Nome da categoria}
- Título e subtítulo da categoria.
- Arquivos como protagonistas (lista ou grade).
- Empty state: "Esta pasta ainda está vazia" + botão "Enviar documento".
- Botão direito na área vazia abre context menu contextual.
- Painel de detalhes à direita para arquivo selecionado.
