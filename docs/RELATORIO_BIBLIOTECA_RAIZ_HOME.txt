1. DIAGNÓSTICO ANTERIOR
--------------------------------------------------------------------------------
A raiz mostrava pastas em cards verticais grandes (estilo dashboard) e, quando
havia documentos sem categoria, uma tabela administrativa completa. O título
grande "Biblioteca" competia com o conteúdo. A composição não parecia uma home
de file manager.

2. REORGANIZAÇÃO DA RAIZ
--------------------------------------------------------------------------------
Nova estrutura em ExplorerRootHome:

  Breadcrumb: Biblioteca (sem título grande)
  ├── Seção "Pastas" — categorias inteligentes (grid de cards horizontais)
  ├── Seção "Recentes" — até 8 documentos por updatedAt (lista compacta)
  └── Seção "Sem categoria" — até 6 itens, excluindo duplicatas dos recentes

Empty state intencional quando não há pastas nem documentos:
"Sua biblioteca está pronta" + botão Enviar documento.

Loading: skeleton de pastas (sem flash de empty state).

4. PASTAS REDESENHADAS
--------------------------------------------------------------------------------

5. RECENTES / SUGERIDOS
--------------------------------------------------------------------------------
Implementado com dados reais:
- pickRecentDocuments() ordena por updatedAt decrescente
- Limite: 8 documentos (RECENT_LIMIT)
- Link "Ver todos" → /biblioteca/recentes quando há mais documentos

Nota: contagem limitada pela paginação atual da API — mesmo risco documentado
na fase File Explorer.
