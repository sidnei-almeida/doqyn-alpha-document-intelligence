RELATÓRIO — Thumbnails em cards da Biblioteca (modo grade)
============================================================
Data: 2026-07-07

OBJETIVO
--------
Exibir preview real (miniatura) nos cards de arquivo do modo grade, usando os
endpoints autenticados de preview já existentes — sem R2 direto, sem mocks.

ENDPOINTS UTILIZADOS
--------------------
1. GET /api/documents/:documentId/versions/:versionId/preview/manifest
   - fetchPreviewManifest (previewManifestApi.ts)
   - trackView=false para não poluir tracking na grade

2. URLs relativas do manifest (via authFetch):
   - PDF: .../preview/thumbnails/:page (primeira página)
   - Imagem: .../preview/image?size=small (thumbnailUrl do manifest)

3. fetchPreviewAssetBlob(url) — baixa blob autenticado e cria objectURL local
   - usePreviewAsset revoga objectURL no unmount/cleanup

Não foi criado endpoint novo.

-------------------

FLUXO DE CARREGAMENTO
---------------------
1. IntersectionObserver — só carrega quando card visível (rootMargin 160px)
2. React Query manifest — key ['document-preview-manifest', documentId, versionId]
   - staleTime 60s
   - refetchInterval 4s enquanto status === 'processing'
3. resolveThumbnailAssetUrl(manifest):
   - pdf_pages → pages[0].thumbnailUrl
   - image → image.thumbnailUrl
4. usePreviewAsset(assetUrl) → objectURL para <img object-contain>

PERMISSÕES E SEGURANÇA
----------------------
- canPreview=false no documento → não busca manifest
- manifest.permissions.canPreview → bloqueia asset
- previewStatus failed/skipped → previewBlocked
- Sem objectKey, presigned URL ou URL R2 no frontend
- Cookies/sessão via authFetch existente

FALLBACK
--------
- Manifest failed / sem thumbnail → FileTypeIcon por extensão
- processing → skeleton + "Preparando visualização"
- loading → skeleton pulse
- canPreview=false → ícone + sr-only
