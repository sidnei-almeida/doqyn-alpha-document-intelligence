Create `src/lib/identifiers/phone.ts`. Import `extractDigits` from `./digits`, `formatBrazilianPhone` and `BR_COUNTRY_CODE` from `./whatsapp`, `type CountryCode` and `defaultCountryForLocale` from `./countryIdentifiers`, and `type SupportedLocale` from `@/i18n/config`. Use relative imports with NO .js extension.

Define a `PhoneCountrySpec` type `{ dialCode: string; placeholder: string; nationalLengths: number[]; format(nationalDigits: string): string }` and export `PHONE_COUNTRIES: Record<CountryCode, PhoneCountrySpec>`:
- BR: dialCode '55', placeholder '+55 54 99999-9999', nationalLengths [10, 11], format(national) => call the now-exported `formatBrazilianPhone(BR_COUNTRY_CODE + national)` so BR output stays byte-identical to today.
- PY: dialCode '595', placeholder '+595 981 234 567', nationalLengths [9]; format(national) => group national into 3-digit blocks joined by spaces and prefix '+595 ' (partial groups allowed while typing, e.g. '9' -> '+595 9', '98123' -> '+595 981 23').
- US: dialCode '1', placeholder '+1 (202) 555-0123', nationalLengths [10]; format(national) => build '+1 (AAA) BBB-CCCC' from the first 3 / next 3 / last 4 national digits, degrading gracefully for partial input ('' -> '+1', '20' -> '+1 (20', '202555' -> '+1 (202) 555').

Implement and export:
- `toE164(rawInput: string, country: CountryCode): string` — `const digits = extractDigits(rawInput, WHATSAPP_MAX_DIGITS)` (import WHATSAPP_MAX_DIGITS from './whatsapp'); if `digits` already starts with the country's dialCode return `digits`, otherwise return `dialCode + digits`. Return '' for empty input.
- `toE164Plus(rawInput, country)` — return '' for empty, else `'+' + toE164(...)`.
- `formatPhone(rawInput: string, country: CountryCode): string` — derive national digits: strip a leading dialCode from `extractDigits(rawInput)` when present, else treat all digits as national; then return `'+' + dialCode + ' '`-style output via `PHONE_COUNTRIES[country].format(national)` (BR spec already returns the full '+55 ...' string; PY/US specs already include the '+<dial> ' prefix). Return '' for empty input.
- `isCompletePhone(value: string, country: CountryCode): boolean` — compute national digit count (digits minus a leading dialCode) and return `PHONE_COUNTRIES[country].nationalLengths.includes(nationalCount)`.
- `defaultPhoneCountry(locale: SupportedLocale): CountryCode` — `return defaultCountryForLocale(locale)`.

Finally, in `src/lib/identifiers/index.ts` add `export * from './phone';` as the last line. Verify no exported identifier name collides with existing barrel exports (phone.ts must NOT re-export `formatBrazilianPhone`, `ensureBrCountryCode`, `normalizeWhatsapp` or any name already exported by whatsapp.ts/countryIdentifiers.ts).
