<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → app runtime | Persisted `doqyn.locale` value is attacker/user-editable free text; it feeds `i18n.changeLanguage` and (transitively via useDocumentLang) `<html lang>` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | getStoredLocale / resolveInitialLocale reading `doqyn.locale` | mitigate | Validate the stored string against `SUPPORTED_LOCALES` allowlist (isSupportedLocale guard) before use; reject unknown values to null so only the three known codes ever reach changeLanguage / `<html lang>` |
| T-02-02 | Denial of Service | localStorage access in SSR/private-mode/quota contexts | mitigate | Wrap all localStorage get/set in try/catch (mirroring libraryDefaultView); on throw, fall back to browser detection rather than crashing init |
</threat_model>
